hoster 산출물 — 단지 안내도

hoster는 Synology NAS를 개인용 Vercel처럼 쓰게 해 주는 셀프호스팅 배포 시스템이다. GitHub에 git push를 하면 GitHub Actions가 이미지내용물이 무엇이든 규격이 같아 어디서든 그대로 실어 나를 수 있는 표준 상자를 빌드해 ghcr.io(이미지 창고)에 올리고, 정문을 열지 않고 미리 뚫어 둔 전용 통로(Cloudflare Tunnel)를 거쳐 NAS 안의 관리사무소(deployer)가 도장(서명)을 확인한 뒤 새 컨테이너그 표준 상자를 실제로 열어 실행 중인 상태로 교체한다. 이 안내도는 아래 10개 문서로 가는 입구이며, 각 문서는 같은 단지·택배·관리사무소 서식의 세계에서 서로 다른 방을 보여준다.

근거: README.md + 01~10 전체 문서 버전 1.0 작성일 2026-08-13
